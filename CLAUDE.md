# Project: Phrase Practice (languagepractice)

This project uses the three-part handoff pattern (`session-handoff-best-practices`
skill) — two durable files, plus an ephemeral re-entry prompt that isn't stored.

**Persistent narrative:** `languagepractice-working.md`
**Latest handoff:** check the most recent `languagepractice-handoff-yyyy-mm-dd.md` in this folder.

When starting a session here:
1. Read the persistent narrative first.
2. Read the latest handoff doc.
3. Verify open items against current file state before acting — the repo,
   the live site, and the GitHub Actions run history are the source of
   truth, not the handoff's memory of them.
